# Roadmap
# Masato Taxi AI 実装ロードマップ

最終更新：2026-07-30

## 現在の段階

Version 1.1の実装後、実際の勤務で使用して操作性と保存状態を確認する。

細かな営業明細、写真保存、OCRは、基本入力機能が安定してから実装する。

---

## Version 1.1 基本入力画面の強化

### 実装内容

- 体調
  - 良
  - 並
  - 悪

- 天気
  - 晴れ
  - くもり
  - 雨
  - 雪
  - 複数選択可能

- 勤務開始時間

- 売上（税抜）

- メーター外売上

- 回数（メーター外は含まず）

- 手上げ乗車回数

- アプリ乗車回数

- 会社無線配車回数
  - 総回数から手上げとアプリ乗車を引いて自動計算

- 走行距離

- 営業距離

- 乗車率
  - 営業距離 ÷ 走行距離 × 100

- 平均単価
  - 売上（税抜）÷ 回数

- 休憩時間

- 勤務終了時間

- メモ

### 運用方針

まず実際の勤務で使用する。

確認する内容：

- 入力順が自然か
- スマートフォンで押しやすいか
- 保存と復元が正常か
- 入力項目が多すぎないか
- 毎勤務継続できそうか

問題があれば、営業明細機能へ進む前にVersion 1.1を修正する。

---

## Version 1.2 営業明細の手動入力

### 実装内容

- 「営業明細を開く」ボタン
- 明細の追加
- 明細の編集
- 明細の削除
- 番号順の表示
- 番号の振り直し

### 明細1件の項目

- 乗車時間
- 降車時間
- 乗車場所
- 降車場所
- 支払い方法
  - 現金
  - 電子払い
  - チケット
  - 長伝
- 金額
- アプリ乗車
- お気に入り乗車

営業明細の金額は、既存の売上（税抜）へ反映しない。

---

## Version 1.3 営業明細一覧の改善

### 実装内容

- 明細カード一覧
- 並べ替え
- 番号の自動振り直し
- お気に入り乗車の一覧表示
- アプリ乗車件数の自動集計

---

## Version 1.4 営業日報写真の保存

### 実装内容

- 1勤務日に複数写真を登録
- 1枚につき約3件の営業記録を想定
- 写真の撮影
- 写真の選択
- 写真のプレビュー
- 写真の並べ替え
- 写真の削除
- IndexedDBへの保存

この段階ではOCRを実装しない。

---

## Version 1.5 写真の文字読み取り

### 実装内容

- 写真ごとの読み取り
- 複数写真の一括読み取り
- 読み取り結果の確認
- 番号、時間、場所、支払い方法、金額、アプリ乗車の抽出

この段階では、読み取り結果を営業明細へ自動確定しない。

---

## Version 1.6 営業明細への変換

### 実装内容

- OCR結果から営業明細の下書きを作成
- 写真順、画面内の上から下の順で並べる
- 番号順への整理
- 重複番号の警告
- 読み取り結果を手動修正
- 確認後に保存

---

## Version 1.7 データ分析

### 分析候補

- 手上げ乗車回数
- アプリ乗車回数
- 会社無線配車回数
- 配車方法別の割合
- 配車方法別の平均単価
- 時間帯別の平均単価
- 曜日別売上
- 天気別売上
- 体調別売上
- 乗車率
- 休憩時間と売上の関係
- お気に入り乗車一覧
- 乗車場所、降車場所の傾向

---

## 当面の優先順位

1. Version 1.1を実際の勤務で使用する
2. 不具合や入力しにくい点を修正する
3. 毎勤務の記録を継続する
4. 時間ができたときにVersion 1.2へ進む
5. 写真保存とOCRは急がず、基本機能の安定後に進める
