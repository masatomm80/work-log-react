## 概要

Masato Taxi AI は、隔日勤務タクシー運転手専用の日報・営業分析アプリです。

売上を記録するだけではなく、営業データを蓄積し、将来的にはAIが営業分析や改善提案を行うことを目的としています。

---

## 開発目的

このアプリは、自分専用の営業支援ツールとして開発しています。

目的は

・入力をできるだけ簡単にする
・毎日の営業を数値化する
・売上を分析する
・営業スタイルを改善する
・長期的にAIへ分析させる

ことです。
