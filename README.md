# M's Taxi AI（React版）

Vite + React + Tailwind CSS で構成された、実行可能なReactプロジェクト一式です。
データは端末の `localStorage` に保存されます。

## バージョン

**Ver.1.0**（2026-08-03 時点の実装内容で確定）

Ver.1.0 は「動くものを安定版として確定する」ことを目的とした区切りです。以降の機能追加は
Ver.1.1 以降として進めます。仕様の詳細・実装根拠は [docs/SPECIFICATION.md](docs/SPECIFICATION.md) を参照してください。

## 機能

### 記録・入力
- 日付ごとの記録・保存（自動保存、更新・再読込しても保持）
- 2024-12-21〜2026-07-20 は「legacy」期間として、日付・売上・メーター外売上・チップ・回数・勤務時間・コメントのみの簡易入力
- 2026-07-21 以降は「current」期間として、体調・天気・手上げ/アプリ乗車回数・走行/営業距離・乗車率・平均単価などを含む詳細入力
- DUTY STAMP（当番なし／日赤／横関／黒字（半日）など）
- 過去の日報一覧表示（MONTHLY LOG）、タップで編集、削除

### 公休日
- 黒字公休日・赤字公休日（出勤／休み）・黒字半日公休日・赤字半日公休日・有給休暇
- 基準日2026-07-21から14日周期で黒字・赤字を交互に自動算出（過去方向にも同じ周期を適用）
- 手動設定は自動算出より常に優先され、日付を移動しても保持される
- 公休日の移動・移動解除

### 集計・一覧
- 21日始まり〜翌月20日締めの月次合算（WORK SCHEDULE / MONTHLY TOTAL / MONTHLY LOG は同じ月度基準で連動）
- MONTHLY TOTAL: 合計売上・出勤日数・今月ノルマ・達成＋−（ノルマ超過はプラス、未達はマイナス表示）
- WORK SCHEDULEカードでの残り勤務日数・予定/勤務済み日数・公休日数の集計
- MONTHLY LOG: 日付・曜日・勤務状態・勤務区分・売上のみのコンパクトな一覧（明け休みは一覧から除外。データ自体は保持）。カードは1回目タップで選択、2回目タップでその日の詳細画面へ移動
- MONTHLY JUMP: 年度ごとに折りたたんだ月度一覧から任意の月度へ直接移動
- 勤務時間の自動計算（開始・終了時刻から算出、手入力で上書き可。current期間では「実務時間」、legacy期間では「勤務時間」と表示）

### 自動保存
- 入力が止まってから800ms後に自動保存（手動保存ボタンも従来どおり利用可能）
- 保存状態を「保存中…／保存済み／保存エラー」で表示
- 日付移動・月度ジャンプ・公休日移動の直前には未保存内容を必ず先に保存し、保存に失敗した場合は移動しない
- 同一内容は再保存しない、空の新規日付は自動保存しない

### データ管理
- CSV書き出し（期間指定＋「現在の月度／今年／全期間」プリセット、Excel対応のUTF-8 BOM付き）
- バックアップ（JSON書き出し、アプリ名・バージョン・作成日時・件数を含む）と、最終バックアップ日時の表示
- 復元（確認ダイアログ表示 → 復元前に現在データを自動バックアップ → 復元。バージョン相違時は警告表示のみで復元は継続可、アプリ名が異なる場合は復元不可）

### PWA / デザイン
- PWA対応（ホーム画面に追加してアプリのように起動、`sw.js` によるService Worker登録）
- スマホ縦画面向けレイアウト、横スクロールなし
- ヘッダーにマスコットロゴを表示、アクセントカラーは `#FFD54A`（落ち着いた黄色）で統一

## 今後の実装予定（Ver.1.1以降）

- 黒字公休日・赤字公休日（休み）でも、通常勤務と同じ入力項目を使えるようにする（現状は黒字半日公休日・赤字半日公休日・勤務日のみ対応）
- その他の未実装・要確認事項は [docs/SPECIFICATION.md](docs/SPECIFICATION.md) の「未実装・検討中・将来予定」「要確認事項」を参照

## Macでのセットアップ（Claude Code）

Node.js 18以上が入っていることを確認してください（`node -v`）。

```bash
cd work-log-react
npm install
npm run dev
```

ターミナルに表示される `http://localhost:5173` をブラウザで開くと確認できます。
同じWi-Fi内のAndroidスマホから確認する場合は、`vite.config.js` で `host: true` を
設定済みなので、`http://<MacのIPアドレス>:5173` でアクセスできます。

## ビルド

```bash
npm run build      # dist/ に本番用ファイルを出力

```

## Vercelへの公開

### 方法A：Vercel CLI

```bash
npm install -g vercel   # 初回のみ
cd work-log-react
vercel                  # 質問に答えて初回デプロイ（プレビューURL発行）
vercel --prod            # 本番公開
```

Vite製プロジェクトなので、Vercelはビルドコマンド・出力ディレクトリを自動検出します
（`vercel.json` にも明記済みです）。

### 方法B：GitHub経由

1. プロジェクト一式をGitHubリポジトリにpush（`node_modules` は `.gitignore` 済みなので含まれません）
2. [vercel.com](https://vercel.com) で「Add New... → Project」からリポジトリをインポート
3. Framework Presetは自動的に「Vite」が選ばれます。そのまま「Deploy」

## スマホのホーム画面にアプリとして追加する

公開後のURLをAndroidのChromeで開き、「⋮」メニュー →「アプリをインストール」
または「ホーム画面に追加」でアイコンを追加できます。

## データについて（重要）

- データはこの端末・このブラウザ内にのみ保存されます（サーバーには送信されません）。
- 機種変更やブラウザの初期化前には、「データ管理」から**バックアップ（JSON）**を
  必ず実行し、ファイルを安全な場所に保管してください。
- 復元時、同じ日付のデータは上書きされます。復元前には自動で現在データのバックアップが作成されます。

## カスタマイズ

- 配色は `src/WorkLog.jsx` 内の Tailwind の任意値クラス（`bg-[#12151A]`、アクセントカラー `#FFD54A` など）を編集してください。
- 備考のタグ候補は `src/WorkLog.jsx` 冒頭の `PRESET_TAGS` 配列を編集してください。
- DUTY STAMPの選択肢は `DUTY_TAGS` 配列を編集してください。
- 月次集計の締め日を変えたい場合は `getPeriodBounds` 関数内の `21` を変更してください。
- アプリ名・バージョン表記（バックアップJSONに記録）は `APP_NAME` / `APP_VERSION` 定数を編集してください。
